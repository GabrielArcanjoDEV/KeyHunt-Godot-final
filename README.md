# 🗝️ Key Hunt

### Um jogo de aventura, exploração e combate desenvolvido em Godot Engine.

\<p align="center">
&#x20; \*\*Key Hunt\*\* é um jogo em que o jogador precisa explorar o cenário, enfrentar inimigos, coletar chaves e superar desafios para alcançar a vitória.
\</p>

---

## 🎮 Sobre o projeto

**Key Hunt** é um projeto desenvolvido como trabalho final da residência em games. O jogo foi desenvolvido individualmente por Gabriel Arcanjo Evangelista Diniz, assumindo as diferentes etapas de desenvolvimento que normalmente seriam distribuídas entre uma equipe.

O projeto busca proporcionar uma experiência de aventura e exploração, combinando combate, perseguição de inimigos, coleta de itens e desafios ao longo da partida.

## ✨ Funcionalidades

- 🧍 Movimentação do personagem.
- ⚔️ Sistema de combate e ataque.
- 👹 Inimigos com inteligência de perseguição.
- 🗝️ Sistema de coleta de chaves.
- 🏡 Cenário com elementos de ambientação.
- 🏆 Tela de vitória.
- 💀 Tela de derrota.
- ⏸️ Sistema de pausa.
- 🎵 Música de fundo com continuidade entre menu e gameplay.
- 🔊 Efeitos sonoros e músicas específicas para vitória e derrota.
- 🔄 Opção de reiniciar a partida.
- 🏠 Opção de retornar ao menu principal.

## 🕹️ Como jogar

O objetivo é explorar o mapa, enfrentar os inimigos, encontrar a chave e concluir o desafio proposto pelo jogo.

### Controles

| Tecla / Botão                               | Ação                     |
| ------------------------------------------- | ------------------------ |
| Teclas de movimentação configuradas no jogo | Movimentar o personagem  |
| Espaço                                      | Atacar                   |
| ESC                                         | Pausar ou retomar o jogo |
| Botão no canto superior direito             | Abrir a tela de pausa    |

### Menu de pausa

O jogo possui uma interface de pausa com as seguintes opções:

- **Continuar:** retoma a partida.
- **Reiniciar:** inicia novamente.
- **Voltar ao menu:** retorna à tela inicial.
- **Sair do jogo:** encerra a aplicação.

## 📦 Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra o Godot Engine 4.7.2 Stable Mono.
3. Importe o projeto pelo arquivo `project.godot`.
4. Aguarde a importação dos recursos.
5. Compile o projeto C#.
6. Execute a cena inicial:

```text
res://Scenes/MainMenu.tscn
```

**Importante:** mantenha a estrutura original de pastas e arquivos do projeto, incluindo `Assets`, `Scenes` e `Scripts`.
