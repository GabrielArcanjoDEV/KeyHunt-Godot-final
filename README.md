<h2>📋 Sobre o Projeto</h2>

<p>
  <strong>Key Hunt</strong> é um jogo de plataforma 2D desenvolvido para explorar mecânicas dinâmicas de movimentação, coleta de chaves e itens, e interações com inimigos. O projeto foi migrado e estruturado utilizando <strong>Godot 4</strong> com scripts em <strong>C#</strong>, aplicando conceitos de Orientação a Objetos e organização modular de cenas e nós.
</p>

<h2>🎮 Como Executar o Projeto</h2>

<ol>
  <li>
    <strong>Pré-requisitos:</strong> Instale o <a href="https://godotengine.org/">Godot Engine 4 (.NET)</a> junto com o SDK do .NET e o Git.
  </li>
  <li>
    <strong>Clone o repositório:</strong>
    <pre><code>git clone https://github.com/GabrielArcanjoDEV/KeyHunt-Godot-final.git</code></pre>
  </li>
  <li>
    <strong>Importe na Godot:</strong> Abra a Godot Engine, clique em <strong>Import</strong>, navegue até a pasta clonada, selecione o arquivo <code>project.godot</code> e clique em <strong>Import &amp; Edit</strong>.
  </li>
  <li>
    <strong>Jogue:</strong> Pressione <strong>F5</strong> dentro do editor para compilar e iniciar o jogo.
  </li>
</ol>
